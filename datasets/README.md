# datasets/

**Last Updated**: 2026-08-17

Raw and cleaned source corpora the backend reads at build time (`CLAUDE.md`
section 3 topology). The Tamil vocabulary, frequency lists, the published
lexicon and the per-Game wordlists cut from it live here.

`datasets/` is **never read directly by the game**. The backend ingests these
sources, classifies and enriches them, and bakes only the finished puzzle bank +
level data into `frontend/public/`; the frontend reads that baked output, nothing
here (Holy Law #1, section 1a data-delivery model).

## Layout

| Path | What it holds |
| --- | --- |
| [`corpus/`](corpus/README.md) | Raw word sources the lexicon pipeline streams, carried over from the retired corpus layer. **Gitignored** - hundreds of MB of third-party lists. |
| [`lexicon/`](lexicon/README.md) | The published all-words lexicon: `lexicon.meta.json` plus one NDJSON partition per class and base ezhuthu. Committed. |
| `wordlists/derived/` | One `game-wordlist` per Game, cut from the published lexicon by `rebuild_wordlists`. Build artifacts - regenerated by one command, never hand edited. Committed. |
| `wordlists/by-length/` | The curated `game_words_{2..6}_letter.json` sets carried over from `yen-tamizh_OLD`. A frequency-and-gloss snapshot of the old dictionary, kept as a reference signal; the derived sets are cut from the lexicon, not from these. |
| `fixtures/` | Shared test fixtures - the ezhuthu golden corpus and the contract valid/invalid payloads both runtimes assert against. |
